# Adventure — learn your code by playing it

An interactive, playable explanation of the six Python components in a school project's `src/student/` folder (`character.py`, `artifact.py`, `enemy.py`, `terrain_generator.py`, `level_generator.py`, `controller.py`).

- **Play** — move your agent on maps generated by the real terrain/level generators, collect artifacts, engage enemies, time patrols, and reach the exit.
- **Watch AI** — runs a JavaScript port of `controller.py`'s Dijkstra planner, verified action-for-action identical to the real Python.
- **Read code** — every file, line-numbered and annotated block by block.
- **Present** — talking points for explaining the project, including two real findings (an "empty range" bug in the straight-path generator, and why a patrol on a 1-wide corridor is impassable).

Single self-contained HTML file — open `index.html` in any browser, or play at the GitHub Pages URL.
